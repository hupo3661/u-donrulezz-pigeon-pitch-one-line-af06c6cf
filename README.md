# Pigeon Pitch, One Line

Entry for the make.fun competition
[u-donrulezz-pigeon-pitch-one-line-af06c6cf](https://make.fun/c/u-donrulezz-pigeon-pitch-one-line-af06c6cf):
the one-line elevator pitch a city pigeon gives investors for its startup.

## The line

> We move a million crumbs a day across this city with zero fuel, zero traffic, and a workforce that works for breadcrumbs — invest in PigeonPost before the seagulls do.

(167 characters, one line. Also saved in `entry.txt`.)

## Run

```sh
python3 main.py
```

Writes the pitch to `/output/entry.txt` and prints it. The program
checks the line is non-empty, a single sentence, and at most 200
characters, then reads the file back to verify it matches.
